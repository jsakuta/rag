## 4. コスト表

### PARAM-001: LOW Azure OpenAI 備考テキストの微差

- **文書A**: 要件定義書 6.4節（Line 606付近）
  > Azure OpenAI (S0) | ~¥2,000 | — | Embedding（text-embedding-3-large）のみ。$0.13/1M tokens
- **文書B**: 導入手順書 付録B（Line 2156付近）
  > Azure OpenAI (S0) | ~¥2,000 | — | Embedding利用のみ（初期構築時は Indexer による生成でコスト増加）
- **矛盾**: 要件定義書は単価情報（$0.13/1M tokens）を備考に記載しているが、導入手順書はその代わりに初期構築時のコスト増加に関する注記を記載している。金額自体（~¥2,000）は一致。備考テキストの観点の差であり厳密には矛盾ではないが、単価情報が導入手順書側に欠落している点を記録する。
- **修正提案**: 修正不要。文書の役割の差（要件定義書=詳細仕様、導入手順書=構築手順）として許容範囲。強いて言えば、導入手順書にも単価を併記すると参照しやすくなる。
