### 6-B. クラウド版: 順位ベース RRF (Reciprocal Rank Fusion)

```
RRF_score(文書) = weight × 1/(vector_rank + 60) + 1.0 × 1/(BM25_rank + 60)
```

- `rank`: 各結果セット内での順位 (1, 2, 3, ...)
- `60`: Azure AI Search の固定パラメータ (k=60、変更不可)
- `weight`: ベクトルクエリの RRF 乗数（現在 **4.5**）

```

  → 4.5 × 1/(5+60) + 1.0 × 1/(1+60) = 0.0692 + 0.0164 = 0.086
