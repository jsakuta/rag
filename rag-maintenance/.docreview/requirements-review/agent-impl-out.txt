1. **IaC が要件上の必須リソース/設定を満たしていない**
- 根拠: 要件では `Azure AI Search`、`Cosmos DB`、`Application Insights`、`Key Vault` を Step 1 の構成要素として明記しています。[要件定義書](/c:/VSCode/rag/rag-maintenance/docs/要件定義書.md#L813) [要件定義書](/c:/VSCode/rag/rag-maintenance/docs/要件定義書.md#L817) [要件定義書](/c:/VSCode/rag/rag-maintenance/docs/要件定義書.md#L819) [要件定義書](/c:/VSCode/rag/rag-maintenance/docs/要件定義書.md#L1246) 一方で IaC は `Managed Identity`、App Service Plan、Web App、Bot 登録しか作成しておらず、Web App 設定も `AZURE_OPENAI_*` のみです。[azure.bicep](/c:/VSCode/rag/rag-maintenance/maintenance-bot/infra/azure.bicep#L25) [azure.bicep](/c:/VSCode/rag/rag-maintenance/maintenance-bot/infra/azure.bicep#L40) [azure.bicep](/c:/VSCode/rag/rag-maintenance/maintenance-bot/infra/azure.bicep#L72) [azure.bicep](/c:/VSCode/rag/rag-maintenance/maintenance-bot/infra/azure.bicep#L96) 実装側は `AI_SEARCH_ENDPOINT`、`COSMOS_DB_ENDPOINT`、`SPO_DRIVE_ID` を前提にしています。[config.ts](/c:/VSCode/rag/rag-maintenance/maintenance-bot/src/config.ts#L2) [config.ts](/c:/VSCode/rag/rag-maintenance/maintenance-bot/src/config.ts#L4) [config.ts](/c:/VSCode/rag/rag-maintenance/maintenance-bot/src/config.ts#L7) [config.ts](/c:/VSCode/rag/rag-maintenance/maintenance-bot/src/config.ts#L15)
- なぜ問題か: 現行 IaC だけでは、要件で対象になっている検索、Cosmos 書き込み、SPO 出力、監視のいずれも成立しません。要件の「動作する Azure 構成」を再現できていません。
- 修正方向: `azure.bicep` に少なくとも `AI Search`、`Cosmos DB`、`Application Insights`、必要なら `Key Vault` と SPO 用設定投入を追加し、Web App に `AI_SEARCH_ENDPOINT`、`COSMOS_DB_ENDPOINT`、`SPO_DRIVE_ID`、`SPO_UPLOAD_FOLDER` を配線してください。

2. **FR-015 の出力対象が「検索結果一覧」ではなくカテゴリ全量になっている**
- 根拠: 要件は「検索結果のシナリオ一覧」を Excel 出力すると定義しています。[要件定義書](/c:/VSCode/rag/rag-maintenance/docs/要件定義書.md#L554) [要件定義書](/c:/VSCode/rag/rag-maintenance/docs/要件定義書.md#L556) DB 設計書も「検索時に AI Search から取得済みのシナリオデータ（メモリ上のキャッシュ）を使用し、追加クエリは発生しない」としています。[データベース設計書](/c:/VSCode/rag/rag-maintenance/docs/データベース設計書.md#L286) しかし実装は `exportExcel` 時にカテゴリごとに `fetchAllScenariosForCategory` を呼び、全件を再取得しています。[agent.ts](/c:/VSCode/rag/rag-maintenance/maintenance-bot/src/agent.ts#L419) [agent.ts](/c:/VSCode/rag/rag-maintenance/maintenance-bot/src/agent.ts#L789)
- なぜ問題か: 検索でヒットした候補だけをレビューする要件なのに、未ヒット行まで Excel に混入します。レビュー対象が膨らみ、要修正判定の意味が変わります。
- 修正方向: Excel 出力はキャッシュ済みの `cached.scenarios` をそのまま使い、カテゴリ分割だけを後段で行う実装に戻すべきです。

3. **FR-014 の `searchId` が検索セッション ID ではない**
- 根拠: 要件は `impactAssessments` に「検索セッションID・シナリオID・判定者・日時を記録」と明記しています。[要件定義書](/c:/VSCode/rag/rag-maintenance/docs/要件定義書.md#L528) DB 設計書でも `searchId` は「パーティションキー。検索セッションID」です。[データベース設計書](/c:/VSCode/rag/rag-maintenance/docs/データベース設計書.md#L115) しかし保存処理は `searchSessionId` を受け取らず、`search-${timestamp}` を新規生成しています。[agent.ts](/c:/VSCode/rag/rag-maintenance/maintenance-bot/src/agent.ts#L330) [agent.ts](/c:/VSCode/rag/rag-maintenance/maintenance-bot/src/agent.ts#L357) [cosmos.ts](/c:/VSCode/rag/rag-maintenance/maintenance-bot/src/cosmos.ts#L57) [cosmos.ts](/c:/VSCode/rag/rag-maintenance/maintenance-bot/src/cosmos.ts#L73)
- なぜ問題か: 判定レコードを元検索セッションへ正しく追跡できません。要件上の監査性と検索結果との対応関係が壊れます。
- 修正方向: `saveNeedsUpdate` に `searchSessionId` を明示的に渡し、その値を `impactAssessments.searchId` に保存してください。

4. **FR-014 の `assessedBy` がユーザー ID/UPN ではなく表示名になっている**
- 根拠: 要件サンプルは `assessedBy` に「ログインユーザーのUPN」を保存するとしています。[要件定義書](/c:/VSCode/rag/rag-maintenance/docs/要件定義書.md#L540) DB 設計書でも「判定者のユーザーID」です。[データベース設計書](/c:/VSCode/rag/rag-maintenance/docs/データベース設計書.md#L119) しかし実装は `context.activity.from?.name` を取り、そのまま `assessedBy` に保存しています。[agent.ts](/c:/VSCode/rag/rag-maintenance/maintenance-bot/src/agent.ts#L354) [cosmos.ts](/c:/VSCode/rag/rag-maintenance/maintenance-bot/src/cosmos.ts#L77)
- なぜ問題か: 表示名は一意でも不変でもありません。要件で求めている監査・追跡粒度に届いていません。
- 修正方向: Teams/Entra から取得できる UPN か AAD Object ID を保存対象に変更してください。表示名は別フィールドに分離するのが安全です。

5. **FR-007 の画像ベクトル化要件が実装・設定に反映されていない**
- 根拠: 要件は FR-007 を「対象（Week 3）」とし、`imageVector`、`dataType: image`、Blob Storage 起点の Indexer B、Azure Vision multimodal skill を明記しています。[要件定義書](/c:/VSCode/rag/rag-maintenance/docs/要件定義書.md#L250) [要件定義書](/c:/VSCode/rag/rag-maintenance/docs/要件定義書.md#L680) [要件定義書](/c:/VSCode/rag/rag-maintenance/docs/要件定義書.md#L682) [要件定義書](/c:/VSCode/rag/rag-maintenance/docs/要件定義書.md#L914) しかしインデックス定義は `contentVector` のみで、画像用フィールドがありません。[index-definition.json](/c:/VSCode/rag/rag-maintenance/scripts/index-definition.json#L12) Indexer も scenarios/faqs の 2 本だけです。[indexer-scenarios.json](/c:/VSCode/rag/rag-maintenance/scripts/indexer-scenarios.json#L31) [indexer-faqs.json](/c:/VSCode/rag/rag-maintenance/scripts/indexer-faqs.json#L29) 検索実装も `dataType` を `scenario | faq` に固定しています。[agent.ts](/c:/VSCode/rag/rag-maintenance/maintenance-bot/src/agent.ts#L728)
