# YAML設定ファイルの全角スペース問題

## 発生した問題
`config/settings.yaml` の `filter_mode: top_k` の末尾に**全角スペース（U+3000）**が混入していた。

```yaml
# 問題のあった行（122行目）
filter_mode: top_k　  # ← 末尾に全角スペース
```

## 影響
- 設定値が `"top_k"` ではなく `"top_k　"` として読み込まれる
- `if self.filter_mode == "top_k":` の比較が **False** になる
- 意図しない else ブロック（閾値モード）が実行される
- TOP-K=130 に設定しているのに、候補数が少なくなる
  - ① Azure: 43件（期待: 130件）
  - ⑤ Azure: 2件（期待: 130件）
  - ⑥ Azure: 18件（期待: 130件）

## 解決策
全角スペースを削除:
```yaml
filter_mode: top_k
```

## 教訓
- YAML設定ファイルで文字列比較が期待通り動かない場合、**全角スペースの混入**を疑う
- 特に日本語キーボードで入力した場合、誤って全角スペースが入ることがある
- 検出方法: エディタで「空白文字を表示」するか、hexdump等で確認
