# データ整理フォルダ構造

## ディレクトリ構成

```
データ整理/
├── シナリオボットメンテナンス管理台帳.xlsx
│   └── シート「メンテナンス管理台帳」（header=3）
│       - 列: No, ステータス, 受付日, 区分, ボット名, 大分類, 変更内容, ...
│       - 変更内容に「行番号：X,Y,Z」形式で変更対象行が記載
│
├── 事務改定内容/
│   └── ①〜⑥の改定内容説明.md
│
├── 事務改定前_マージ版シナリオ/
│   └── {番号}マージ版シナリオ_{ボット名}.xlsx
│       - 正解IDの行番号はこのファイルのExcel行番号
│
├── 事務改定前後_個別シナリオ/
│   └── {番号}{改定名}/
│       ├── 修正前/
│       │   └── {サブフォルダ}/シナリオ_*.xlsx  ← テキストマッチングの元データ
│       └── 修正後/
│           └── ...
│
└── 最新_マージ版シナリオ/
    └── 全事務改定適用後の統合版
```

## ボット名対応

| 台帳の表記 | 正解ID用 |
|-----------|---------|
| スマイル | smile-bot |
| 内部事務 | naibujimu-bot |
| 相続 | souzoku-bot |
| 取引時確認 | torikaku-bot |

## 正解ID生成

詳細は `correct-id-generation` メモリを参照。

**重要**: 単純計算では1行ずれる。テキストマッチングが必須。

スクリプト: `scripts/generate_correct_ids.py`
出力: `input/multi_stage_input.xlsx`
