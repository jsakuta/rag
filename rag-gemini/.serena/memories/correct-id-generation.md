# 正解ID生成の仕組み

## 概要

正解IDは、メンテナンス管理台帳の行番号を基に、マージ版シナリオの実際の行番号を特定して生成する。

**重要な発見：単純な計算では全て1行ずれる。テキストマッチングが必須。**

## 正解ID形式

```
{ボット名}_{マージ版Excel行番号}
例: smile-bot_130, naibujimu-bot_641
```

## 生成スクリプト

`scripts/generate_correct_ids.py`

### 処理フロー

1. メンテナンス管理台帳から行番号を抽出
2. 対応する個別シナリオファイル（修正前）を読み込み
3. 台帳の行番号に該当する行のテキスト内容を取得
4. マージ版シナリオで同じテキスト内容の行を検索（テキストマッチング）
5. マッチした行のExcel行番号を正解IDとして出力

### テキストマッチングのキー

Lv1〜Lv10列を`|`で結合してマッチングキーを作成：
```python
key = "諸届|住所変更|受付可否について|個人事業主口座|..."
```

### 台帳行番号の解釈

台帳の行番号は事務改定によって解釈が異なる：
- Excel行番号（ヘッダー含む）: idx = row_num - 2
- カテゴリ内行番号（1始まり）: idx = row_num - 1

スクリプトは両方のパターンを試してマッチする方を採用。

## フォルダ構造

```
データ整理/
├── シナリオボットメンテナンス管理台帳.xlsx  ← 台帳番号と行番号の情報源
├── 事務改定前_マージ版シナリオ/             ← 正解IDの行番号はここを参照
│   ├── ①マージ版シナリオ_smile-bot.xlsx
│   ├── ②マージ版シナリオ_souzoku-bot.xlsx
│   └── ...
└── 事務改定前後_個別シナリオ/               ← テキストマッチングの元データ
    ├── ①.../修正前/*.xlsx
    ├── ②.../修正前/*.xlsx
    ├── ③.../修正前/{サブフォルダ}/*.xlsx   ← サブフォルダあり
    └── ...
```

## 注意点

1. **計算ベースは使わない**: 単純な計算（カテゴリ開始位置+行番号）では1行ずれる
2. **テキストマッチング必須**: 修正前ファイルの内容とマージ版シナリオを照合
3. **新規追加行はスキップ**: 修正前ファイルに存在しない行（新規追加）はマッチングできない
4. **出力先**: `input/multi_stage_input.xlsx`
