### Step 2: 差分MDの更新

マージ版行番号が特定できたら、差分MDを以下のように更新：

**変更前:**
```markdown
変更箇所 1: **カテゴリ内行3** (Excel行367)
- 行番号: 367
```

**変更後:**
```markdown
変更箇所 1: **カテゴリ内行3** (マージ版行XXX)
- 行番号: XXX
```

また、ヘッダーテーブルの「Excel行」列を「マージ版行」に変更。

### Step 3: 正解ID生成スクリプトの更新

`scripts/generate_correct_ids.py` の行番号抽出パターンを更新：

**変更前:**
```python
# パターン: (Excel行123)
excel_match = re.search(r'\(Excel行(\d+)\)', line)
```

**変更後:**
```python
# パターン: (マージ版行123) または (Excel行123)（後方互換）
excel_match = re.search(r'\((マージ版行|Excel行)(\d+)\)', line)
if excel_match:
    num = int(excel_match.group(2))
```

## 重要な発見：行番号は一致している

マージ版Excelファイルを確認した結果、**個別シナリオの行番号とマージ版シナリオの行番号が完全に一致**していることが判明しました。

### 確認結果（全21行）

| 事務改定 | ボット | 個別シナリオ行 | マージ版行 | 状態 |
|---------|--------|--------------|-----------|------|
| ③ | smile-bot | 367 | 367 | 一致 |
| ③ | smile-bot | 437 | 437 | 一致 |
| ③ | naibujimu-bot | 97, 100 | 97, 100 | 一致 |
| ③ | naibujimu-bot | 139, 142 | 139, 142 | 一致 |
| ③ | naibujimu-bot | 643, 708 | 643, 708 | 一致 |
| ③ | souzoku-bot | 147, 168 | 147, 168 | 一致 |
| ③ | torikaku-bot | 22, 25, 35, 88-90 | 22, 25, 35, 88-90 | 一致 |
| ④ | naibujimu-bot | 641 | 641 | 一致 |
| ⑤ | smile-bot | 238, 269, 317 | 238, 269, 317 | 一致 |

### 結論

行番号の変換は**不要**です。現在の差分MDに記載されている「Excel行」はそのままマージ版の行番号として使用できます。
